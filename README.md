智能门户平台(AI生成的，会有一些部署的问题，具体看发行版本)
项目简介
本项目是基于 React + Node.js + Python 搭建的全栈微服务智能门户平台，整合前端展示、多后端微服务、本地AI大模型能力，支持 Windows 一键安装部署，专为课程考核与项目演示设计。
版本说明 v1.0.0
功能交付
- 全栈一体化系统：React前端 + Node网关微服务 + Python业务服务
- 八个后端微服务：登录、文章、AI系统、培训、资源、投影、信息代理、接口网关
- 文章管理模块：支持发布/编辑/删除/查看文章、阅读量统计、本地AI生成文章与内容润色
- 一键安装程序 Inno Setup 打包，自动复刻完整目录结构，部署零复杂配置
交付特性
- 配套一键启动程序，已封装为 EXE 程序，无需手动执行 PowerShell 脚本
- 全相对路径适配，支持安装至任意盘符、任意文件夹，无路径报错、无文件找不到问题
- 完整卸载支持，控制面板可一键清理所有项目文件，无残留缓存
使用说明
- 下载 Version1.0.0Setup.exe 安装包或 7z 源码压缩包
- 双击安装程序，自定义本地安装路径
- 通过桌面快捷方式一键启动全套前后端服务
- 需手动下载并启动 Nacos 服务注册中心，否则后端服务无法正常注册运行
- 依赖 MySQL 数据库，配套数据表结构已随安装包附上，导入后方可正常读写数据
- AI 功能依赖 Ollama 本地大模型，默认模型为 qwen2.5:7b，可在源码中自由切换版本
- AI 系统需使用配套自定义提示词，模型命名为 normal-assistant:latest
- 项目原有配置为局域网开发IP，正式使用需统一修改为 127.0.0.1 本地回环地址
- 项目自带熔断机制，未修改IP、后端未启动时，前端页面仍可正常访问，但展示栏图片、动态数据无法正常加载
补充说明
- 当前为课程考核正式版本，完整功能可正常演示、部署、运行
- 详细技术文档、全平台兼容性优化将在后续迭代版本补充完善
技术架构
前端技术栈
- React 单页应用
- Ant Design 组件库
- Axios 接口请求封装
- 前端熔断、路由鉴权、数据可视化模块
后端技术栈
- Node.js：统一接口网关、请求转发、负载适配
- Python：核心业务微服务实现
- Nacos：微服务注册、发现、配置管理
- MySQL：业务数据持久化存储
- Ollama：本地离线AI大模型推理服务
部署方式
方式一：EXE 一键安装部署（推荐）
下载 Release 发布的 Version1.0.0Setup.exe，无脑安装，桌面快捷方式一键启动整套系统。
方式二：源码部署
克隆项目源码，安装前端依赖、配置 MySQL、启动 Nacos、部署 Ollama 模型后，通过启动程序拉起全套微服务。
